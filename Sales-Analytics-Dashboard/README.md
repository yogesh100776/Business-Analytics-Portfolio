# Sales Analytics Dashboard

## Project Overview

Developed an interactive Sales Analytics Dashboard in Power BI to analyze sales performance, profitability, customer segments, regional trends, shipping modes, and future sales forecasts.

## Business Objective

Provide management with insights into sales performance and identify opportunities for revenue growth and operational improvement.

## Tools Used

- Power BI
- Power Query
- Microsoft Excel
- DAX

## Data Preparation

### Excel

- Removed duplicate records
- Standardized date formats
- Validated data consistency
- Prepared source data for analysis

### Power Query

- Cleaned and transformed raw sales data
- Renamed columns for consistency
- Handled missing values
- Created calculated columns
- Converted data types
- Structured data model for reporting

## Key KPIs

- Total Sales
- Total Profit
- Quantity Sold
- Average Delivery Time

## Dashboard Features

- Regional Analysis
- State Filters
- Category and Sub-Category Analysis
- Payment Mode Analysis
- Shipping Mode Analysis
- Year-over-Year Sales Trends
- Profit Trends
- Sales Forecasting

## Key Insights

- Consumer segment generated the highest sales.
- Western region contributed the largest share of revenue.
- Standard shipping mode accounted for the majority of orders.
- Forecasting model provides short-term sales projections.
