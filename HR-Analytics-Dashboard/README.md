# HR Analytics Dashboard

## Project Overview

Designed an HR Analytics Dashboard to identify workforce trends, employee attrition patterns, and workforce demographics.

## Business Objective

Help HR teams understand employee turnover and improve workforce retention strategies.

## Tools Used

- Power BI
- Power Query
- Microsoft Excel
- DAX

## Data Preparation

### Excel

- Data validation
- Data cleaning
- Missing value handling
- Formatting and standardization

### Power Query

- Employee data transformation
- Data type corrections
- Data modeling
- Creation of reporting dimensions

## Key KPIs

- Employee Count
- Attrition Count
- Attrition Rate
- Average Salary
- Average Age
- Average Years at Company

## Dashboard Features

- Attrition by Department
- Attrition by Education
- Attrition by Salary
- Attrition by Job Role
- Attrition by Age Group
- Job Satisfaction Analysis
- Gender Analysis

## Key Insights

- Highest attrition observed among employees aged 26–35.
- Attrition concentrated within specific job roles.
- Lower salary groups experienced higher turnover rates.
